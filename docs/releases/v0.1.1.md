EScope 的首个公开版本：一个轻量、本地优先、默认只读的 Elasticsearch 桌面查询工作台。
The first public release of EScope — a lightweight, local-first, read-only Elasticsearch desktop workbench.

## Highlights / 主要能力

- **Connections / 连接**：多集群，Basic / API Key / Bearer，自定义公共 CA，身份、版本与许可证证据检测。
- **Query / 查询**：Monaco JSON DSL 编辑器与可视化构建器，多标签并行查询，PIT 分页与取消。
- **Results / 结果**：虚拟化表格、原始 JSON 与结构化文档视图，单元格筛选、AND/OR 条件组、文档详情与对比。
- **Aggregations & charts / 聚合与图表**：单值指标、一级 `terms` / `date_histogram` 桶，柱状/折线图、双轴与会话参考线。
- **Data views & cluster insight / 数据视图与集群概览**：本地数据视图、显示格式、受限运行时字段；健康、节点、分片、索引与 Mapping 只读查看。
- **Assets & export / 资产与导出**：保存的查询与参数模板、执行历史、工作区恢复；CSV / JSONL 复制与受限 PIT 全量导出。
- **Desktop / 桌面体验**：明暗主题、强调色、密度与字号、中英文界面，与各平台适配的融合式标题栏。

## Notes / 说明

- **Unsigned builds / 未签名**：Windows SmartScreen 可能提示，选择“更多信息 → 仍要运行”。macOS 首次打开若提示“已损坏”或无法验证开发者，
  请将应用拖入“应用程序”后执行 `xattr -dr com.apple.quarantine /Applications/EScope.app`。
- **Windows installer / Windows 安装包**：当前用户级安装，无需管理员权限；缺少 WebView2 时自动下载安装。
- **Credentials / 凭据**：密钥只保存在系统凭据库。本版本仅 Windows 接入凭据库；macOS / Linux 上需要密码或令牌的连接暂不可用，无认证连接可正常使用。
- **macOS / Linux**：可构建并运行，但原生窗口、凭据与安装体验尚未完成实机验收，欢迎反馈问题。
- **Read-only / 只读**：本版本不写入文档、Mapping 或集群设置；TLS 证书校验始终开启。
- **Elasticsearch**：面向 7.10+（PIT 分页与全量导出），人工基线 7.17.25；8.x / 9.x 兼容性仍在验证。
- AI 助手入口在本版本中隐藏。The AI assistant is hidden in this release.
