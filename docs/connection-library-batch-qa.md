## 接口与持久化

- `connections_load/save/delete/cleanup` 使用受限合同，旧元信息 IPC 仍拒绝已绑定凭据的记录。
  网络请求只接受稳定连接 ID，不接受 URL、方法、认证头、凭据引用或临时秘密。
- 保存将元信息、凭据引用和 CA 放入同一 SQLite 事务。写入新密钥前先记录 prepare；
  失败保留旧目标/凭据/CA，新孤立秘密仍被清理队列追踪。提交后才清理被替换的秘密。
- 公开连接只返回认证类型、`hasCredential`、`hasCustomCa`，这些布尔值表示绑定元信息，
  不承诺系统密钥库当前可读或证书当前有效。不会回显秘密、引用或 PEM。
- 清理返回 `complete/pending/incomplete`。`incomplete` 的 remaining 为 null，不能当零；
  达到重试上限的记录保留，不伪装已删除。保存已提交不会因后续清理失败回滚或报未保存。
- 换端点时 keep 不复用旧凭据或旧 CA；重命名保留身份。CA 限 64 KiB、16 个公共证书块，
  私钥与无效内容拒绝。自定义根只用于所属可信快照，所有客户端共享并发许可。
- schema v5 从 v4 升级：增加 `connections.ca_pem` 与 `saved_query_library`。
  查询库单行上限 4 MiB、最多 100 项，草稿 DSL 上限 256 KiB；不完整 DSL 可保存。
  旧版本无法打开高版本 schema，不自动降级或覆写损坏库。
- `connection_access` 仅调用注册的根信息、`_security/_authenticate` 和固定
  `_security/user/_has_privileges`。角色信息按有界字段投影，不返回整份安全响应。
  版本反馈不代表权限或许可证授权，也不门控既有搜索。
- `saved_queries_load/save/export` 没有任意存储键或前端指定路径。
  恢复使用新查询 ID，仍绑定原连接 ID；原连接已删除时不能执行，也不按名称重绑。
- 桌面导出通过 `tauri-plugin-dialog` 选择目标，同目录临时文件写完、flush/sync 后替换；
  取消、失败、已保存明确区分。浏览器仅报告下载已请求，不宣称磁盘写入成功。
  导出大小上限 16 MiB，不隐式取下一页或重新查询。
- CSV 保留数值原始 token，文本公式防护与 RFC 4180 转义；JSONL 每行是完整原始 hit，
  仅去 token 间空白。CSV 本身没有类型信息，第三方表格软件自动转换不在字节无损保证内。
- 浏览器会话适配只保存元信息/查询草稿到内存，刷新即清除；拒绝秘密保存，
  真实桌面失败不会静默切换至 session。
