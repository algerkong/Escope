| 范围 | 已实现 | 边界 |

| 尺寸 | TanStack Table 列宽为事实来源；`colgroup` 和无障碍隐藏占位保留完整宽度，尺寸/顺序/显隐变化重新估算范围 | 不测量单元格文字覆盖保存列宽；收窄到小表时钳制滚动，不按滚动查询 |
| 渲染 | 表头和每行只挂载窗口及少量保留列；行仍使用原页/行身份，不创建全列 TanStack cell 对象 | 已加载数据、字段发现、排序和按行字段查找仍在内存，不声称解析或内存已虚拟化；列设置列表尚非虚拟列表 |
| 交互 | 原有排序/列宽/双击自适应、显隐/重置、dnd-kit 换序、详情/对比/筛选动作保持 | 表头排序仅已加载行；列操作不改 DSL、执行或续页 |
| 焦点 | 保留当前/上次焦点列、必要前后及首尾可聚焦列、拖拽源/目标邻列、按下列和原生选区端点 | 只保留少量离散列，不展开中间全部列；离开结果面清理会话保留项，原生 Tab/触控/屏幕阅读器仍待验 |
| 复制 | 原生选区跨未挂载列或含格式化值时，按当前可见列顺序与真实已加载行重建整单元格原值 | 不补回隐藏列、不改行选择；普通无缺列的原值局部选区继续原生复制，不把显示格式写入结果或导出 |
| 隔离 | 表格/JSON/标签往返保留各自滚动和选择；表格实例绑定查询与执行身份，新执行清理旧窗口/选区并从原点开始 | 列偏好仍由父层保留，结果、选区、窗口范围和滚动不新增持久化，不影响旧 PIT 或冻结对比 |
| 无障碍 | 保留原有双语可访问控件，表格报告完整可见列数，已挂载表头/数据单元格报告逻辑列索引 | `aria-colcount`/`aria-colindex` 与 JSDOM 焦点断言不是屏幕阅读器或原生布局通过证明 |

新增内部 `useResultColumnWindow` 负责库适配、占位与交互保留，不手写通用虚拟化引擎。
