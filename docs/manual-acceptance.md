## 通用检查项

| 代号 | 检查内容 |
| --- | --- |
| [布局] | 中英文、日夜/四强调色/系统高对比、字号 12–20/两档密度/大字号、100%/200% 缩放、窄窗口：不重叠、不裁切、不撑宽，长名/值/JSON 内部滚动可达 |
| [键盘] | Tab/Shift+Tab 顺序与可见焦点，Esc/关闭/删除/弹窗往返后焦点回位；原生 `<select>`/`<datalist>`、中文 IME；屏幕阅读器朗读名称与状态，`role="status"`/`role="alert"` 不互相覆盖 |
| [审核] | 完整 DSL 预览后显式应用，应用后须明确运行；草稿/目标/端点/执行/字段证据变化使旧预览作废；无效可视化或待应用条件阻止应用与运行 |
| [证据] | 当前 Mapping/field caps 未检查/缺失/类型冲突/不可搜索/FLS/runtime 遮蔽/读取失败均不当可用；不用旧成功或截断证据，查询授权仍由后端判断 |
| [快照] | 操作本身不请求、不开 PIT、不改 DSL；新执行/新快照/离开即清理，重开无旧状态；旧 PIT 续页仍用原 DSL/时间/排序/游标；索引标签只显式生成同目标新查询 |
| [重启] | 桌面重启只恢复约定的草稿/定义/已应用 DSL；不执行、不开 PIT，不恢复结果/行选择/页码/待应用条件/会话绑定；已删连接不重绑 |
| [升级] | 隔离备份上升级：失败保留原 user_version 与全部文档；损坏/未知版本/只读/CAS 冲突/未知完成不覆盖、不伪报成功；旧版读新库拒绝、不降级 |
| [文件] | 原生对话框：取消只报取消；覆盖、不可写/磁盘满/系统中断与已保存分开；处理未返回不能关闭或伪报成功；浏览器只报“已请求下载” |
| [原值] | 长整数/长小数/指数/转义/超安全整数保持原 token，复制取完整原值；剪贴板拒绝有提示 |

状态：**自** = 领域/JSDOM/临时 SQLite/mock 自动化已过，原生/真实待验；**人** = 待人工；
**建** = 已构建或已实现分支，待原生；**未** = 功能未齐，暂不可执行。真实 ES 项均需当次授权环境。
