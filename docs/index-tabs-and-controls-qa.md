## 实际交付

| 范围 | 实现与边界 |
| --- | --- |
| 索引标签 | 每个稳定连接 ID + 精确去空白索引目标对应一个标签，与查询按打开顺序排列。重复点击仅激活已有标签，不重跑；首次明确打开才执行只读预览 |
| 空入口 | 原“数据预览”只保留索引打开入口，没有共享执行槽位。手填索引/模式也打开独立标签；索引标签目标不可编辑，有刷新与基于该索引新建查询入口 |
| 连接上下文 | 激活有效连接的标签同步顶部、资源栏与新查询目标。连接选择写入串行化并按最后用户意图接收完成；迟到的连接选择不能覆盖新标签。已移除连接的历史标签不被重绑 |
| 状态保持 | 各文档独立保留结果视图、精确本地排序、列顺序/宽度/显隐、页码、表格与 JSON 滚动位置。刷新只重置该执行的页码；设置、语言、主题和标签选择不执行查询 |
| 关闭与焦点 | 活动标签关闭回退相邻标签，最后一个关闭回到空入口。后台关闭不抢编辑器焦点；支持中键、标签方向键/Home/End/Delete、文档区域 Ctrl/Cmd+W，保留 IME/模态保护及 macOS Control-W 文本操作 |
| 查询草稿 | 可视化中未完成的条件和校验问题跨索引/查询标签保留，仍阻止执行旧 DSL。未完成条件也参与关闭确认；格式化撤销与诊断按文档保存 |
| 请求生命周期 | 关闭仅取消对应文档并释放 PIT。关闭后重开使用新文档 ID；旧搜索、旧续页和迟到的 openPit 不覆盖新标签，迟到 PIT 尽力清理 |
| 表格细节 | 继续使用 TanStack Table/dnd-kit；自适应列宽为拖动柄、排序图标和文档按钮留位。隐藏排序列后仍可直接清除排序，大字号表头使用受约束尺寸 |
| 统一控件 | 真实 select 的统一主题外壳、Lucide 箭头，支持的 Chromium 渐进增强 picker；复选框/单选框/滑块、禁用/错误/焦点与高对比回退同步。设置、模型、连接、AI、分片、可视化和顶栏接入 |
| 样式修复 | 降低基础 input 选择器特异度，让查询名称/编辑器/紧凑表单样式生效；长模态标题和按钮换行；下拉弹层/表格/对话框滚动边界；可视化移除重复横向内边距 |
| 其他排查 | 元数据刷新中和失败后保留已有列表并标记旧数据；字段目标统一 trim；分片状态消失后重置筛选；取消续页显示停止而不是失败；命令执行恢复焦点；复制回调按作用域隔离 |
