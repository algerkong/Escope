# EScope 工程契约

正式实现必须遵守的功能契约与交互/安全边界，自 `AGENTS.md` 迁入并按领域去重；`AGENTS.md` 只保留协作规则与核心底线。
查询语义的产品叙述见 [产品设计](product-design.md)，设置、连接与窗口交互见 [设置与快捷键](settings-and-shortcuts.md)，
各批实现证据与待验项按领域记录在 `docs/acceptance/`。开发前阅读受影响章节，契约变化须同步本文件。
第 1 节为跨领域共同规则，其余各节只写本领域特有条款与上限。

## 1. 共同规则

### 1.1 不自动执行与显式审核

- 启动、恢复、连接切换、设置往返、外观/语言变化、编辑/查找/格式化，以及保存、加载、复用、导入任何定义，
  都不触发查询执行。
- 改写 DSL 的功能（时间范围、筛选、排序、参数、查询期字段、聚合构建、图表定义复用与固定筛选加载）先给出完整
  DSL 预览，再由用户显式应用；应用不执行，仍需明确运行。源草稿、执行、目标、连接或证据变化使审核作废，须重新预览。
- 各功能只改写自身声明的部分，其余手写内容保留；不能无损处理的手写内容整体保留或整次拒绝，不静默覆盖或丢弃。
- 未应用的编辑只存在于会话/弹窗状态，不进入恢复存储；应用后的 DSL 沿用既有草稿/历史/恢复规则。

### 1.2 字段证据

- field caps、Mapping 与当前 DSL runtime 声明只作保守门控证据，且只采用同连接 ID + 端点 + 完全相同请求目标的
  当前已核对结果；刷新中、失败、旧目标或来源不符时不展示、不复用旧证据。
- 证据不代表权限、执行或排序成功；field caps 也不是执行快照、Mapping/nested 结构或当前 DSL runtime
  （nested 另需 Mapping 证据，见 §6.3）。
- 未知不当否定，缺失/空清单不推断字段或索引不存在；未检查、缺失、类型冲突、不可搜索/不可聚合分别处理；
  不猜 keyword/子字段、nested 路径或类型转换。
- runtime 字段只认当前 DSL 中的实际声明（执行结果以执行 `rawDsl` 为准），不从未应用的视图定义或旧执行推断。

### 1.3 原值、精度与完整性

- 以接收到的原 JSON token 为准，按精确十进制/BigInt 处理；复制、排序与导出取原值，显示格式不进入复制或请求。
- 未返回（缺失）、null、空容器/空数组与 0 各自独立；缺失只表示未返回，不推断索引缺失，不回填旧 `_source`。
- JSON 数值精度、部分失败、取消、数据过期和结果未知必须按契约处理，不伪装完整成功；未知完成不当作成功。

### 1.4 有界输入与整次拒绝

各节所列数量、字节、层数与字符上限一旦超出即整次拒绝：不截断、不丢弃坏成员后放行、不静默修复；
未知键或非法形状同样整次拒绝。

### 1.5 会话态生命周期

文档对比、单条详情、聚合视图、图表与参考线均为会话态，绑定执行快照身份，按各节规定在新执行或离开
标签/视图/设置时清理；它们不额外请求、不改 DSL/PIT、不持久化。

## 2. 工作台与标签

### 2.1 启动、设置与恢复

- 无本地恢复记录时默认进入查询工作台的索引打开入口，AI 默认收起；已有工作区恢复上次标签，
  已保存的启动偏好按设计生效。
- 连接、模型、集群、节点、分片和索引在设置右侧显示，保留左侧导航；不新建 Dashboard 或第二套管理首页，
  局部详情、编辑与危险确认可使用对话框。
- 设置往返保留草稿、结果和视图。

### 2.2 标签与连接上下文

- 连接身份使用稳定 ID，不使用名称；零连接显示空状态，单连接隐藏选择器，多连接入口同步。
- 明确打开索引新增独立数据标签，按稳定连接 ID + 索引去重，重复打开只定位、不重新执行，刷新是明确动作；
  结果、列设置和分页与其他索引/查询标签独立。
- 标签固定绑定连接，结果绑定不可变执行快照；旧请求、已取消请求和其他连接的响应不得覆盖当前结果。
- 激活有效连接的标签同步工作区连接上下文；持久化选择串行化，旧完成回调不覆盖新意图。
- 关闭标签清理对应请求/PIT，后台关闭不抢输入焦点；已删除连接的历史标签不得重绑。

### 2.3 索引标签上的改写功能

索引标签目标锁定，改写 DSL 或目标的功能不在其上原地生效：

| 功能 | 索引标签行为 |
| --- | --- |
| Data View 配置 | 不接受 |
| 查询时间范围 | 拒绝该配置 |
| 单元格/分组/nested 筛选与启停 | 只显式生成同目标新查询，不改原标签；保留真实来源快照身份，不伪造新查询已执行 |
| 服务器排序 | 沿用显式新建查询入口 |
| 聚合构建 | 不渲染入口，只用显式新建同目标查询 |
| 图表定义库 | 不出现工具条 |

## 3. 连接与认证安全

- 正式版本不默认注入演示连接或数据，真实失败不得静默回退到 mock。
- 前端通过受约束的类型化 IPC 访问后端，不提供任意 URL、方法和认证头代理。
- 默认只读，未知操作拒绝；写入必须经过后端权限校验与绑定目标、最终请求的审核流程。
- SQLite 保存元信息与凭证引用；密钥存系统密钥库，不进入前端持久化、日志、文档或导出；
  密钥库不可用时不降级为明文保存。
- ES 认证只从数据库生成的不可变 `TransportSnapshot` 解析，请求须匹配连接 ID、归一化端点、认证类型与引用；
  缺失/损坏凭据不降级为无认证发送，不缓存或跨目标复用秘密。
- 认证设置仅走 `connections_*` 合同，元信息与凭据变更分离；保存的元信息/引用/CA 同事务，提交后清理以
  complete/pending/incomplete 返回，未知不当作已清除；更换端点不沿用旧凭据/CA。
- 自定义 CA 仅公共 PEM，默认根、证书与主机名验证保留；不增加忽略证书校验开关。
- 身份/权限诊断为显式只读检查，monitor 拒绝、未知与 API 不支持分开，不阻止授权索引查询。
- 版本/部署/许可诊断不以主版本或许可类型推断可用；Serverless 按返回的构建标记识别，功能报告与实际操作验证分开。
  仅许可/功能报告可在后端内存缓存 60 秒/最多 16 连接，按可信传输与集群/精确版本指纹隔离；
  每次仍查身份/权限/根信息，旧代次不得回填。

## 4. 查询编辑器

### 4.1 Monaco

- 正式查询 DSL 使用本地延迟加载的 Monaco；每工作区按标签持有模型、撤销栈和视图，关闭标签/工作区才释放，
  不序列化模型。
- 原始 DSL 仍为事实来源：挂载不回写规范化文本，显式格式化仅改空白且可撤销。
- 只接本地词法着色与 editor worker，不启用 JSON schema 网络读取、跨模型词语建议或任意 REST；
  CSP 不开放远程脚本、blob worker 或 unsafe-eval。原生 IME/worker/布局单列验收。

### 4.2 DSL 本地补全

- 仅按当前模型的已知 JSON 位置，从当前 field caps、当前 DSL runtime 声明及参数定义生成单个字面文本编辑。
- 不从结果值、未应用视图定义、其他标签词语或参数输入值生成建议，不展示脚本文字，不自动查字段或执行。
- 上限：DSL 256 KiB/64 层、字段目录 4,096 项、名称 1 KiB、候选 100 项。
- 参数只补明确整值占位内的名称，不修改模板；无 snippet/附加编辑/命令或隐式接受。

## 5. 时间与参数

### 5.1 查询时间范围

- 可选 v1 定义与绑定：最近 N 秒/分钟/小时/天（天固定 24 小时）或完整绝对本地时间；N 最多 10,000，
  跨度最多 3,660 天；时区为 UTC/IANA/固定偏移，夏令时不存在/歧义时间拒绝。
- `date` 不舍入非整毫秒，`date_nanos` 保留精确非负 i64 纳秒；统一左闭右开 UTC 边界。
- 原查询完整保留在受校验的 bool wrapper 中；同字段手写范围与未知混合检索拒绝；范围显式应用或移除。
- 只有已绑定范围在明确运行、PIT 打开前按客户端时钟冻结，续页/历史沿用原绝对边界；
  其他手写日期数学/脚本不被隐式改写。
- 手改 DSL 或目标即解除托管，并保留草稿的绝对字面量。收藏保留相对意图；历史恢复仅还原实际 DSL，
  不重新启用相对范围。
- runtime 日期字段只认可当前 DSL；时间元数据不进入查询/PIT/导出请求。定义交换不携带托管，
  须另行确认草稿预览边界或参数模板的导出语义。

### 5.2 查询参数

- 可选的版本化定义；整值占位 `{"$param":"name"}` 不替换键名、字符串片段或目标；未替换参数不得执行。
- 输入值不独立持久化，已应用 DSL 遵循原有草稿/历史规则。交换见 §11.2。

## 6. 筛选与排序

会话筛选列表（单元格/分组/nested，含禁用项）最多 32 条、8 个非空组，每值 4 KiB，最终 DSL 256 KiB。

### 6.1 单元格筛选

- 以执行原值及同目标字段证据生成：keyword 用 term、text 用显式短语；缺失/null/空数组不自动转为索引缺失，
  exists/missing 单独选择。
- 单元格入口仅接顶级字段的有界标量/数组元素（平面原值），拒绝未知/冲突/nested/含点路径；
  runtime 声明须与当前 DSL 一致且值来自 fields，不回填旧 source。
- 待应用列表仅会话内保存，存在时阻止运行/保存旧 DSL；应用时保留手写条件和时间绑定；
  无效可视化草稿或源草稿/执行/目标变化阻止应用。
- 应用后不自动改参数模板，也不从 DSL 反推持久筛选定义。

### 6.2 布尔分组

- 组内/组间 AND/OR，每条恰属一组；所有新增 OR 显式写 `minimum_should_match: 1`。
- 新增组与原 query 取 AND 交集并处于 filter；排除只作用于所属分支，不改原 should/MSM/评分。
- 遗漏/重复/未知成员、深层组、组级 NOT 或自定义最少匹配数拒绝，不隐式展开或丢条件。
- 分组变化需重新预览，时间绑定/排序/参数模板/旧 PIT 保留。会话分组不直接进入恢复存储；
  显式固定使用 §6.5 的独立定义合同，不序列化会话绑定。

### 6.3 nested 筛选

- 复用同目标 Mapping 原文与 field caps，二者实际索引集合须非空且一致；Mapping 限 2 MiB/128 索引/4,096 个检查字段，
  只接顶级 nested 路径与直接标量字段，值为显式输入。
- 不从扁平路径、对象/数组或含点键猜嵌套，不套用该路径下的平面 runtime；缺失/冲突/不可搜索或未知对象标志拒绝。
- 同组编译为一个 nested（score_mode=none、ignore_unmapped=false）；内部否定不等于排除父文档，
  父文档排除置于 nested 外且仍属于所在 OR 分支。
- 仅同路径条件可移组；同条件可在不同 nested 组重复表达独立对象，同组重复拒绝。
- 结构变化需重审；不解析改写手写 nested。

### 6.4 启停与会话绑定

- 待应用会话筛选可逐条启停；可选 `enabled` 只接受布尔值，缺省启用。禁用保留定义/原值/组归属，
  仍计入 32 条/8 组及重复校验，只跳过当前字段证据；重新启用须重新校验。启停变化作废审核。
- 无启用成员的组不参与 AND/OR 或 nested 父排除，不生成空 bool/nested；全禁用时逐字预览基线 DSL 与时间绑定，
  首次应用不能提交空操作。
- 待应用列表（含已绑定定义全部移除的零项编辑）阻止运行/保存；取消编辑不改已应用定义。
- 应用后以会话内深冻结的基线/已应用文档、目标、观察快照和定义副本保持绑定；混合列表保留禁用项，不要求丢弃。
  后续从基线重建，不重复追加 wrapper，不从任意 DSL 反向推断。
- 全禁用或移除最后一项须全文审核，只移除确实绑定的新增条件；全禁用保留定义，移空后解除。
- 手改 DSL/目标/时间/排序/参数等导致失配时阻止覆盖；明确解除仅遗忘会话定义，保留当前 DSL/结果。
- 仅本会话实际核对生成的绑定可用，反序列化副本不恢复托管；只有实际应用的 DSL 持久化。
- 新执行不移动基线时间，接纳新条件后保留本次核对的观察快照；旧 PIT/历史不改。

### 6.5 固定筛选

- 独立 v3 本地定义（100 组/256 KiB，每组 32 条/8 个非空布尔组，值 4 KiB）；兼容 v1 平面 mapped/v2 mapped nested，
  读取不改写；显式新增升级，删除保持原版本，已存版本不降级。存储见 §10.2。
- 平面或显式顶级 mapped nested 条件保留精确字面量、组关系、必填布尔启停与父文档匹配；同 nested 组对应同一对象，
  内部否定与父排除分开，独立组允许相同条件，同组重复拒绝。
- 平面 runtime 可附带精确 runtimeMapping，复用七类型/同名 source 或有界内联 Painless（§7.2），每段 4 KiB、
  每组去重声明 32 项/64 KiB；类型/源码/可选语言形状须一致，同字段不混用声明。
  日期/IP/geo_point runtime 只支持存在性，nested runtime 整组拒绝。
- 只从已应用 DSL 提取，保存时包括禁用项都须核对；现场值需要真实观察，不从视图库补齐。
  完整定义与字面量确认、脚本文字另行全文确认后显式保存。
- 加载只产生同连接 ID + 完全相同目标的待审副本，不覆盖已有待应用/已绑定筛选。保存字面量与执行原值明确区分；
  无观察时 snapshot 为 null，重新检查当前 mapped 字段与 runtime 遮蔽。
- 首次加载的启用 nested 项须在打开本次审核后新取 Mapping/field caps，核对非空且一致的实际索引集合、
  显式路径/直接字段与类型；必须显式发起本次检查，打开前缓存或更早在途请求的完成不代替它。
- 启用的 runtime 字面量只匹配当前已应用 DSL 的精确声明，不插入/替换/运行脚本，不冒充 fields 原值；
  禁用项仍计配额并校验完整声明/结构，启用后重审。
- 库不含端点/认证/结果/PIT/DSL/基线；删除不改会话副本；绑定不恢复，新真实观察不改其身份。

### 6.6 服务器排序

- 独立草稿审核，最多 8 个平面标量字段，方向/次序、缺失和未映射策略明确；只接受有界白名单选项，
  未知或复杂手写 sort 整体保留，不能借清空绕过。
- 以同目标 field caps 及当前 DSL runtime 声明为证据；`non_aggregatable_indices` 不可忽略。
- 仅改 sort，保留手写条件、时间绑定、精确值和参数模板；未应用排序仅在弹窗内。
- 新排序只在明确运行时生效，旧 PIT 续页仍取原快照；不修改后端授权或全量导出规则。表头本地排序见 §8.1。

## 7. Data Views

- 有界本地定义（文档 v1，100 项/256 KiB），固定连接 ID；存储与绑定规则见 §10。
- 草稿保存所选定义副本，库中修改/删除不改旧草稿或执行快照；手改目标解除关联。
- 字段发现只作为证据，不能绕过 Mapping 写入审核；默认时间字段不自动注入范围或执行。

### 7.1 字段格式

- 可选 v1 定义（32 项/16 KiB），仅数字、百分比、IEC 字节和 UTC 日期白名单；数值使用原始十进制文本/BigInt，
  日期来源明确，超限/不兼容值保留原样，无脚本/HTML/URL。
- 格式随执行与历史深拷贝，不从当前库/草稿回填；排序、复制与导出仍取原值；不进入搜索/PIT/导出请求，
  不随查询定义交换导出。

### 7.2 查询期字段

- 可选 `runtimeFields` v1（32 项/64 KiB），仅 keyword/long/double/boolean/date/ip/geo_point；同名 `_source` 取值或
  内联 Painless（每段 4 KiB），无 stored script/params/lookup/composite/忽略错误。
- 最终 DSL 无损合并后进入预览；不同的手写同名定义不覆盖，字段遮蔽/未验证证据须可辨。
- 后端独立校验 `runtime_mappings`，仍只走查询/PIT，不执行前端脚本或开放 Mapping 写入。
- 表格读对应 `fields` 原值，缺失不回填旧 `_source`；PIT 不冻结脚本输出。导出与交换见 §11。

## 8. 结果与文档

### 8.1 结果表与列

- 行选中使用主题 token，按记录身份保持，刷新执行后不得误选新数据。
- 列交互使用 TanStack Table 与 dnd-kit；表头排序只作用于已加载行且标明范围，不当作全索引排序；
  排序/拖拽/列宽操作不隐式修改或执行 DSL。
- 宽表用 TanStack Virtual 窗口化已加载列，仍按 50 行本地分页；宽度/列身份由 Table 保持，
  焦点/拖拽/选区端点只会话保留。
- 跨未挂载列复制按可见列顺序和真实行重建原值，不补隐藏列。
- 新执行清理旧窗口/选区和滚动，保留列偏好；不把 JSDOM 几何或挂载数量当原生性能基准。

### 8.2 文档对比

- 仅接同一执行的两条已加载记录，按接收页/行位置核对真实 hit，不按 `_id` 或显示序号重查。
- 冻结原始记录与连接 ID/端点/请求目标/执行身份；区分元数据、`_source`、`fields` 和当前执行 runtime。
- 按 JSON 结构与精确十进制比较。
- 有界读取每记录 1 MiB/64 层/100,000 token/数字 4,096 字符，合计 4,096 对比项、每页 50 项。
- 新执行或离开标签/设置关闭对比，续页不替换已捕获记录。

### 8.3 单条详情

- 复用对比的有界读取与真实页/行，打开时冻结 hit、原接收页和执行来源。
- 结构目录最多 4,096 节点（含容器/数组成员/缺失诊断）、累计路径 1 MiB，每页 50 项；使用相对 hit 的 JSON Pointer，
  搜索已加载路径，折叠不丢原值；不把 JSON 路径/类型当 Mapping/nested。
- 元数据/source/fields 分离，runtime 只取执行 DSL 的 fields。
- 可复制原值/容器/记录/原接收页，均保留 token。
- 新执行按快照身份清理、离开关闭，关闭释放。

### 8.4 字段侧栏

- 只展示 §1.2 规定的已核对 field caps，来源按需展开。
- 报告标记与保守门控分开；按类型保留冲突、类型索引与搜索/聚合限制索引。
- 无效清单不丢坏成员后放行；损坏根索引集合/字段类型结构整次拒绝；类型索引不从根集合补齐。
- 原字段列表 150 项上限保持，索引明细按需挂载、每页 20 项；操作不额外查询或执行。
- 字段诊断被拒绝不代表查询被拒绝。

## 9. 聚合与图表

### 9.1 聚合读取

- 只按执行 `rawDsl` 与单个原接收页解释：顶层六类单值指标（sum/avg/min/max/value_count/cardinality）与单层
  terms/date_histogram，后者可带直接指标；未知/高级聚合保留原文，不从响应形状、当前草稿或字段证据猜类型。
- 原 token/null/缺失/0/空桶、cardinality 近似、terms 误差/遗漏与页级部分状态各自独立。
- 不相加 PIT 页或桶计数为文档总数；日期不补桶、不推结束边界；PIT 不承诺冻结脚本输出。
- DSL 256 KiB/原页 1 MiB、32 定义/4,096 桶、名称 1 KiB/64 层/100,000 token/数字 4,096 字符；每页 50 桶。
  视图/解析结果只会话保留，新快照/离开清理。
- 聚合页不把已加载文档导出冒充桶导出；图表、聚合构建和定义库使用统一审核主入口。

### 9.2 聚合构建

- 只表达读取器可解释的形状：至多一个单层 terms/date_histogram 分组加其直接指标，或无分组的一组顶层单值指标。
- 只改写顶层 `aggs`（已有 `aggregations` 长写法原地改写，不建第二块）；`query`、已绑定时间 wrapper、`sort`、
  `runtime_mappings`、其余根属性与保留条目值文本按原字节不变；块被改动时其条目之间的空白重新排布，
  仍需在完整 DSL 预览中核对。
- 不属于该形状的顶层条目按原值文本保留并列出，生成名称与其同名时整体拒绝，不静默覆盖手写定义。
- 以下情形整体拒绝：多分组、分组与顶层指标混排、超 31 指标、`aggs`/`aggregations` 并存、非对象块、
  非法 JSON 或未替换参数、名称/size/间隔/时区形状错、证据不符、定义总数超 32、构建后读回不一致。
- 字段门禁按当前 field caps 与当前 DSL runtime 声明保守判定，要求 aggregatable 且类型落在矩阵内；
  含点/nested/冲突/仅未映射/带 metadata/未检查分别拒绝。
- 构建不产生请求、不打开 PIT、不执行。预览按行对象与字段读取身份绑定，行/目标/草稿/证据变化作废；
  应用前重新从源 DSL 读回并核对 `matchesQueryDraft` 与目标身份；审核打开时禁用运行与保存。
- 未应用行只存活在弹窗状态。文档计数取命中总数与桶 `doc_count`，不为其伪造 `filter`/`global` 聚合。

### 9.3 图表

- 只绘聚合读取已核对的单个接收页条目；图型按执行 DSL 类型定为单值/terms 条形/date_histogram 折线，
  不从响应形状或当前草稿猜类型。
- token→double 转换独立核对严格十进制、有限性、下溢、安全整数与最短往返精度，绘制值与原 token 并列保留；
  缺失/null/非数字/超范围只列为未绘制并给原因，绝不画成 0。
- 不重排桶、不补空桶、不推结束边界、不在客户端解析或格式化日期；折线在跳过处断开。
- 近似、误差未知/未报告、遗漏计数、Top N 非完整分布、仅桶起点、精度损失计数与接收页限制随图显示；
  图范围标注冻结索引/接收页/度量/绘制比返回/冻结时间边界原文。
- 最多 200 桶，超出整次拒绘不截断；轴标签最多 12 个，显示截断不改原值。
- 绘图使用延迟加载的 Visx 纯 SVG 运行时：无 canvas 测量、无 eval、无远程脚本。
- 只有明确开关与度量选择器；无点击/悬停查询、无导出、无 Dashboard，图表视图本身无持久定义
  （可选定义库见 §9.6，也不保存图型开关）。

### 9.4 双轴

- 第二度量只在同一已核对条目的 terms 条形/date_histogram 折线中显示，取同一批返回桶与同一 `chartMeasures` 集合，
  不新增图型种类。
- 与主度量同名、未知名称、不属于该条目、单值条目，以及第二度量无可绘图值时整次拒绝，不静默回落为单序列，
  各自给原因。
- 两序列各自独立核对精度、未绘制清单、近似/断线提示并按度量分列显示，不合并也不互相掩盖。
- 左右数值轴用同一域规则各自独立定标（仍含 0），不共用刻度、不归一化、不暗示可比；轴标题与图范围行点名
  左右轴归属度量并声明无共用单位。
- 200 桶配额与 12 个轴标签上限不因双轴放宽或减半（两序列共用同一条目）。
- terms 用同槽位并列柱，主实心/次空心虚线，主柱宽度缩小但 y/高度不变；误差/遗漏/Top N 属于共享桶范围。
- 任一值轴跨度非有限时整次拒绘，不输出 NaN 几何。
- 双轴不持久化：图表定义仍是 v1 单 `measure`，不保存图型或第二度量；schema v10 不变，无新迁移/IPC，交换格式不变。

### 9.5 会话参考线

- 仅接已核对的 terms 条形/date_histogram 折线，每图共用最多 4 条（含轴外值）；显式选择左/右轴，
  无已绘制第二度量不能选右轴；添加/编辑须明确应用，取消不改已应用线。
- 保留不超过 4,096 字符的严格 JSON 数字原文，复用绘图范围/精度检查；doc_count 要求精确安全整数；
  非有限/下溢/跨度溢出拒绝。
- 参考线不参与轴域计算；轴外原始十进制值只列示不绘制、不钳到边界；不改原柱/点几何、顺序、断口或原值。
  轴归属、精度损失与重合线独立列示，线型不只靠颜色区分。
- 绑定执行来源/接收页/聚合/两侧度量，其变化或关闭图表/离开结果/标签/设置时清理已应用线和编辑器；
  同执行续页不换所选页，改当前草稿不重绑旧图。
- 不进入定义/恢复/交换；schema v10、图表定义 v1 不变；注释另行开发。

### 9.6 图表定义

- 可选的本地 v1 定义（连接 ID + 目标模式 + 分组 + 指标 + 绘图度量），只保存名称/类型/字段与 size/间隔/时区字面量；
  不保存解析结果、绘制数值、字段能力证据、时间边界、端点、认证对象、凭据引用或结果正文，
  也不保存图型开关（图型仍由执行 DSL 决定）。
- 定义内的 `draft` 必须通过聚合构建的形状校验；度量在有分组时取 `doc_count` 或分组内指标名，
  无分组时取该单值指标名；不符整条拒绝，不修好再保存。
- 上限 100 条/256 KiB/名称 120 字符码点/字段与度量 1 KiB/指标 31 个/size 1–1000/间隔 64 字符/时区 100 字符；
  含点字段可作字面量存储，但在构建预览处按 `fieldPath` 拒绝。
- 保存/加载/复用/复制/重命名/删除一律不请求、不开 PIT、不执行。复用只在连接 ID 与目标完全一致且连接仍存在的
  查询标签上启用，只播种构建行。
- 重命名只改名称，复制生成新 ID；存储与连接绑定见 §10.2。定义库 IPC 仅 `chart_definitions_load/save` 两条受限命令。

### 9.7 旧图表库兼容与结果快捷保存

- 旧库（`saved_chart_library`）通过图表定义库中的独立兼容入口查看；只有同连接/精确目标且无损支持的定义可播种
  统一构建审核，旧排序、min_doc_count、混合分组等不能丢弃后复用。
- 结果快捷保存仅从执行 `rawDsl` 的原定义读取，不按响应桶数、子指标名称或当前草稿猜字段/size/间隔；
  不支持的选项/元数据整次拒绝。完整定义与字面量确认后保存；新执行或离开结果视图清理保存对话框。

## 10. 存储与恢复

### 10.1 通用规则

- 桌面使用 SQLite，失败不得降级为内存保存；浏览器预览明确使用 session 内存适配，并标注不跨重启。
- 各本地库为独立的类型化存储：串行保存并比较修订号，损坏、未知版本或冲突不自动覆盖；定义库读不插行。
- 定义固定连接 ID：同 ID 不换绑，新增定义须核对连接仍存在。

### 10.2 存储清单

| 存储 | SQLite 表（引入迁移） | 特有规则 |
| --- | --- | --- |
| 查询库 | `saved_query_library`（`005_connection_settings.sql`） | 只保存有界草稿/收藏定义；普通保存及导入比较已读完整内容，冲突不强制覆盖；恢复不重绑已删除连接 |
| 工作区与执行历史 | `workspace_recovery`（`006_workspace_recovery.sql`） | 恢复文档 v1，见 §10.3 |
| Data Views | `data_view_library`（`007_data_views.sql`） | 文档 v1（§7） |
| 固定筛选 | `pinned_filter_library`（`008_pinned_filters.sql`） | 定义 v3（§6.5）；CAS 与新 ID 的连接存在性核对在同一事务内，既有 ID 定义不可覆盖或换目标；已删连接保留身份且可删除，不重绑；未知完成须重载 |
| 图表定义 | `chart_definition_library`（`009_chart_definitions.sql`，schema v8 → v9） | 定义 v1（§9.6），SQLite 单行文档；immediate 事务内比较 revision 串行 CAS，未知完成需显式重载；越界计数器由 SQL CHECK 拒绝；新增 ID 须在同事务内确认连接仍存在，删除连接保留历史 ID 与定义且不重绑、不静默删除 |
| 旧保存图表 | `saved_chart_library`（`009_saved_charts.sql`） | 另一分支的 v9 表，经兼容入口查看（§9.7） |
| 合并升级 | 补齐上两表（`010_merged_chart_libraries.sql`，schema v10） | 见 §10.4 |

### 10.3 工作区与执行历史恢复

- 独立的类型化恢复存储：恢复文档 v1，随 schema v6 引入，经 v8 至 v10 的升级未改恢复合同。
- 标签/DSL/可视化草稿/列布局可恢复；结果正文、PIT、认证对象、行选择和页码不持久化。
- 未知完成的执行标为中断，不伪装成功。

### 10.4 schema v10 合并升级

- main/dev 两个历史 v9 分别使用 `saved_chart_library` 与 `chart_definition_library`；合并后 schema v10 仅补齐缺少的表，
  保留两库原文、修订号和连接身份，不自动转换、合并或删除旧定义。
- 升级前按 SQLite 返回的已知历史 DDL 核对（仅忽略 LF/CRLF 差异）；两表皆缺、异常表结构或未来版本拒绝，不静默修复。

## 11. 导出与交换

### 11.1 结果导出

- 已加载 CSV/JSONL 导出不额外查询，保留原值。
- 全量导出另行确认不可变目标/最终 DSL，以独立 PIT 有界流式扫描，不复用结果页游标；全量导出拒绝 runtime mappings。
- 桌面保存目标由原生对话框选择，未完成文件带 `.partial-*`；只有有效空页、刷盘和原子替换后才报完整保存。
  取消/失败/限额与未知清理分开；浏览器下载请求不代表磁盘写入完成。

### 11.2 查询定义交换

- 本地交换仅含选中的查询定义，参数化查询使用模板；无连接端点、认证、凭据引用或结果正文，字面量仍需用户核对。
- 不带 Data View 配置（时间托管见 §5.1），但显式应用的 DSL/脚本文字按查询定义规则交换。
- 导入逐项明确映射本地 ID + 端点或未绑定，同事务核对目标并仅新增查询；冲突规则见 §10.2 查询库。

### 11.3 图表定义交换

- 选中定义可导出为 `escope-chart-definitions` v1 文档（只含目标模式、分组与指标的名称/类型/字段、size/间隔/时区字面量、
  绘图度量与不透明来源标签，≤100 条/1 MiB）。
- 绝不含端点、真实连接 ID、认证类型、凭据引用、密钥、解析结果、绘制数值、字段能力证据、时间边界、结果正文、PIT、
  历史或草稿 DSL；定义本身边界不因交换放宽。
- 敏感键与认证样式检查由 TS 与 Rust 共享，在文档任意层级命中即拒；无头导出文档仍需用户核对字面量。
- 导入必须逐个来源显式映射到本地连接 ID + 端点；映射缺失/重复/未知键/非法 ID 整次拒绝，profiles 变化触发
  `exchangeTargetChanged` 需重审。
- 因定义库不变量要求 `connectionId` 必填、新增 ID 需事务内确认连接存在、同 ID 不换绑，**交换不提供也未实现未绑定导入**。
- 导入只以新 ID 一次追加，不覆盖既有 ID/定义/草稿/收藏，同名允许重复。
- 桌面 `chart_definition_exchange_read/save/import` 三条受限命令在同一 immediate 事务内比较 revision、重检映射端点后写入；
  前端逐字核对返回的整段追加；冲突/端点变化/超限/损坏存储不写盘，未知完成需重载。
- 导出/导入/映射/写入一律不请求、不开 PIT、不执行；导入后仍须匹配标签 + 显式复用 + 完整 DSL 预览 + 显式应用。
- 浏览器导出为显式下载请求（不验证磁盘）；交换未新增迁移（引入时 schema 为 v9）。

## 12. AI
