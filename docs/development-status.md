## 1. 当前已正式接入能力清单

以下为截至 2026-10-15 自动化通过的正式功能与设计边界：

### 1.1 查询工作台与多标签
- **索引打开入口与标签隔离**：无本地恢复记录时，查询工作台默认显示索引打开入口；首次明确打开索引新增独立数据标签并只读预览，重复打开相同连接 ID + 索引只定位已有标签，不重查。索引目标锁定，刷新和基于索引新建查询为明确动作；不覆盖其他索引或查询的目标、草稿、结果和列设置；AI 默认收起。
- **工具栏与底栏收拢**：索引预览的状态、精确命中数与视图/刷新操作收拢在单一工具栏，重复标题/HTTP 地址不再常驻；表格/JSON 底栏合并计数与操作，快照说明按需查看，异常提示保留。
- **标签排布与生命周期**：索引/查询标签按打开顺序排列；有效标签同步顶部和资源栏连接，新查询跟随该上下文。关闭回退相邻标签并清理对应请求/PIT，后台中键关闭不抢焦点；标签方向键与文档区 Ctrl/Cmd+W 可用。
- **融合式桌面顶栏**：Windows/Linux 自定义窗口控制，macOS 原生交通灯 overlay，与现有 header 同层。浏览器不模拟窗口按钮；各平台的原生拖拽、缩放和交通灯对齐仍待人工验收。

### 1.2 Monaco 查询编辑器与智能补全
- **延迟加载 Monaco 编辑器**：本地 JSON 着色/校验、无损格式化、撤销/重做及当前模型的字面量查找；每标签模型、撤销栈、选区/滚动独立，关闭释放，不跨重启保存模型。重复键拒绝、双语错误行列/marker；长整数/小数/转义/未知 DSL 不经数值重序列化。本地 editor worker/字体、无 JSON 语言服务/远程 schema，编辑/设置/语言/恢复不执行；加载失败保留原文。本地校验不代表脚本编译或 ES 授权，原生 IME/worker/布局待验，详见 [编辑器 QA](query-monaco-editor-qa.md)。
- **DSL 本地补全**：已接已知查询/sort/fields/_source 字段和整值参数占位内的名称；只用同连接 ID/端点/目标的当前 field caps、当前 DSL runtime/参数定义，不从结果/参数输入值生成建议，不展示脚本文字。刷新中/失败/旧目标不回填；单 token 无损字面插入、真实建议列表与撤销/重做，双语来源/空状态/ARIA。DSL 256 KiB/64 层、目录 4,096 字段、100 候选；不猜子字段/nested/权限、不改模板、不自动查字段/执行，不启用跨标签词语、snippet/附加编辑或命令，详见 [补全 QA](query-completions-qa.md)。
- **可视化/DSL 双模式切换**：AND/OR、term/match、单边界 range、exists/missing、数量与单字段排序；保留评分上下文与未修改 DSL。不支持的复杂/nested/脚本语法保留原文，不静默丢条件。未完成条件跨标签保留、参与关闭确认，并阻止按钮或快捷键执行保留的旧 DSL。

### 1.3 时间范围与筛选体系
- **查询工具栏时间范围审核**：最近 N 秒/分钟/小时/天（固定 24 小时），或完整绝对本地起止时间，UTC/IANA/固定偏移；最多 10,000 单位且总跨度不超过 3,660 天。左闭右开、date 不舍入非整毫秒、date_nanos 保留精确纳秒；无效/歧义/不存在的本地时间拒绝。原查询保留在有界 wrapper 中，完整 DSL 预览后显式应用/移除；手写同字段范围不覆盖。相对时间在明确执行、打开 PIT 前按客户端时钟冻结，续页不移动；手改 DSL/目标解除托管，保留草稿中的绝对字面量。字段证据不当权限，runtime 日期须已应用到实际 DSL。普通索引标签不接受时间配置，不做自动刷新、任意日期数学或日历取整。详见 [时间范围 QA](query-time-range-qa.md)。
- **单元格筛选**：取执行原值，支持顶级 keyword/数字/布尔的包含/排除、text 分析短语与独立 exists/missing；数组明确选一个元素，不从 null/空数组推断索引缺失，不猜 `.keyword`。字段证据须检查，runtime 必须与当前实际 DSL 一致；未知/冲突/nested/含点路径拒绝。最多 32 条、每值 4 KiB；会话内待应用列表经完整 DSL 预览后显式应用，不自动执行。原手写条件、时间绑定及执行结果保留，索引标签仅生成同目标新查询；未应用列表不恢复，应用后 DSL 才走既有保存规则。详见 [单元格筛选 QA](query-cell-filters-qa.md)。
- **布尔筛选组**：待应用筛选可组成最多 8 个非空组，组内和组间分别选择 AND/OR，总计仍限 32 条。每个 OR 显式 `minimum_should_match: 1`，排除仅在所属分支内；新增组与完整原 query 取 AND 交集且不评分，原 should/MSM/评分、时间、排序和参数模板保留。新组/移组/成员或证据变化需重新预览，分组本身只在会话中，旧 PIT 不改；不支持任意深层组、组级 NOT 或自定义 MSM，详见 [布尔筛选组 QA](query-filter-groups-qa.md)。
- **显式 Nested 条件**：成功或部分结果的工具栏提供显式 nested 条件入口，复用原筛选弹窗，读取同目标 Mapping 与 field caps，实际索引集合须一致。首批仅顶级 nested 路径和直接标量字段，值为显式输入，不从单元格对象/数组或扁平路径推断；日期/IP 仅存在性，别名、深路径和路径下 runtime 拒绝。同组条件属于同一嵌套对象；对象内排除与“父文档不存在匹配对象”分别选择，每组 `score_mode: none`、`ignore_unmapped: false`，父文档排除不会越出所属 OR 分支。仍限 8 组/32 条，完整 DSL 预览后应用，证据/结构变化需重审；旧 PIT 和时间/排序保留。索引只生成同目标新查询，未应用定义不恢复；不反向转换已有手写 nested，详见 [Nested 筛选 QA](query-nested-filters-qa.md)。
- **待应用会话筛选启停**：待应用会话筛选支持逐条启停，禁用保留原值/操作/组归属，仍计 32 条/8 组配额；没有启用成员的组不参与 AND/OR 或 nested 父排除。全部禁用逐字预览源 DSL，不提交空操作（针对首次应用）；每次启停重新审核，重新启用须当前字段证据。详见 [启停 QA](query-filter-enablement-qa.md)。
- **已应用筛选会话绑定**：已应用筛选保留有界会话定义及禁用项，以深冻结的基线/已应用文档和真实观察快照绑定。后续从基线重建，不重复包裹 DSL；全禁用经审核恢复精确基线且保留定义，移除最后一项仍须审核，零项待应用编辑继续保护运行/保存。取消编辑不改已应用定义，混合应用不再丢弃禁用项。手改 DSL/目标、时间、排序或参数等使绑定失配时阻止覆盖；明确解除只遗忘定义，不改当前 DSL/结果。旧 PIT 不改，索引只显式生成同目标新查询且不伪造执行身份，不自动执行。会话定义/绑定不直接进 IPC 或恢复存储，重启仅恢复已应用 DSL；详见 [会话绑定 QA](query-filter-session-qa.md)。
- **固定筛选规则库 (Pinned Filters)**：
  - 平面 mapped、显式顶级 mapped nested 和有界平面 runtime 条件支持固定、删除和同目标复用；全文核对定义与字面量后保存，保留布尔组、精确 token、启停、路径与对象内/父文档否定；同 nested 组对应同一对象，独立组可重复相同条件；nested runtime 仍整组拒绝固定。
  - 固定库 v3 最多 100 组/256 KiB，每组 32 条/8 个非空组、每值 4 KiB；既有 ID 不覆盖或改目标。兼容 v1/v2 读取、不自动改写；显式新增升级，删除保持原版本，已存版本不降级。
  - runtimeMapping 只取当前已应用 DSL，保存类型/精确源码/可选语言，禁用项也核对声明；脚本每段 4 KiB，去重声明 32 项/64 KiB，七类型白名单，date/IP/geo_point runtime 仅存在性。完整源码另行确认，不从视图库或未应用配置补齐，不保存整份查询。
  - 加载只产生同连接 ID + 完全相同目标的待审副本，标明已保存字面量；没有执行时不创建假快照。启用 nested 项须打开审核后新取 Mapping/field caps，核对实际索引集合、路径/类型及 runtime 遮蔽，不使用旧缓存；runtime 字面量只核对当前已应用 DSL 中相同声明，不注入/替换/运行脚本。完整 DSL 预览后显式应用，不自动执行；索引锁定 DSL 缺少声明时不能借加载改写它或创建新查询。
  - 已有待应用或绑定筛选不能被加载覆盖；删除库中条目不改会话副本或已应用 DSL。schema v8 独立行与串行 CAS，损坏/未知版本/冲突不覆盖。详见 [固定 runtime QA](pinned-runtime-filters-qa.md)、[固定 nested QA](pinned-nested-filters-qa.md) 与 [固定筛选 QA](pinned-filters-qa.md)。
- **服务器排序审核**：服务器排序有独立审核入口，最多 8 个平面标量字段，显式方向、优先级、缺失位置与兼容的 `unmapped_type`；同目标 field caps/实际 runtime 声明只作证据，不当作授权或执行成功。部分不可聚合索引、未检查/缺失/冲突/不支持分别处理，不猜 keyword 或隐式类型转换；复杂手写 sort 不覆盖，完整 DSL 预览后显式应用/移除，只改排序、保留时间与原条件。表头排序仍仅已加载行，旧 PIT 续页沿用原排序；索引标签先显式新建查询再编辑。未应用选项不持久化，应用不执行、不改参数模板，详见 [服务器排序 QA](query-sort-qa.md)。

### 1.4 数据呈现、对比与聚合
- **执行契约与 PIT 续页**：源码已接入 ES 索引/字段/Mapping 读取、快照查询/取消、部分结果与无损表格/JSON/文档详情，统一使用可信连接快照中的无认证或 Basic/API Key/Bearer 认证；显式 sort 的可分页查询在第一页前开启 PIT，按最新 ID 与原始游标续页，过期要求从第一页重跑。取消/openPit/关标签/改地址的迟到响应隔离；JSON 默认两空格缩进，复制仍使用原文。
- **会话内基础聚合展示**：查询结果可明确打开会话内聚合视图：按执行 DSL 读取 sum/avg/min/max/value_count/cardinality，以及单层 terms/date_histogram 和直接指标；原值/null/缺失、近似/误差/遗漏与页级部分状态可辨。每次选择一个原接收页和聚合项，50 桶分页；不累加 PIT 页、不取当前草稿/字段能力解释旧响应。日期只读返回起点与执行选项，不补桶或推算结束边界；未知类型保留原文，复制仍为原 token。DSL 256 KiB/接收页 1 MiB、32 定义/4,096 桶等限额整次拒绝；不保存结果/视图、不额外查询。原文/来源按需展开，聚合页不把文档导出当成桶导出，详见 [聚合结果 QA](query-aggregations-qa.md)。
- **基础图表与聚合定义**：合并后复用延迟 Visx 单值、terms 条形与 date_histogram 折线，图表显式开关且原桶表保持可用；原 token、近似、误差、未绘制值与页级来源分开，200 桶上限，不补桶、不推结束边界，不查询或修改快照。统一构建/保存/交换入口，结果快捷保存读取原执行字段、size/间隔并明确审核，旧库仍可查看和同目标无损复用。历史本地图表见 [原图表 QA](query-aggregations-chart-qa.md)，合并验证见 [分支合并 QA](main-dev-merge-qa.md)。
- **会话级参考线**：terms/日期折线可显式添加、编辑和删除最多 4 条参考线，明确选择当前左/右值轴，无第二度量不能选右轴。保留严格数字原文、精度损失与轴外原因，轴外值不绘制、不钳到边界；跨度溢出拒绝，不扩大数据域或改变原柱/点几何。执行来源/页/聚合/度量变化或关闭/离开清理，同执行续页保持所选页；不查询、不改 DSL/PIT，不进入图表定义、恢复或交换。长值和重合线在图外独立列示，虚线不只靠颜色区分；原生验收另列，见 [参考线 QA](query-aggregation-chart-references-qa.md)。
- **TanStack Table / Virtual 列窗口化表格**：完整列发现、横向滚动、列升降序、拖拽/键盘换序、列宽/双击自适应、显隐与重置。排序只针对**已加载文档**，数字原文精确比较后按 50 行分页，不修改或执行 DSL，不声称全索引排序。列布局与页码在 JSON/标签/设置往返后保留，表格/JSON 滚动位置也按标签保持；可直接清除隐藏列排序，重新执行重置页码、行选择与滚动。超过 24 个可见列时窗口化表头/单元格，保留完整宽度、逻辑列索引和交互端点；跨未挂载列按真实行与当前列顺序复制原值，不补隐藏列。详见 [列窗口 QA](result-column-window-qa.md)。
- **持久行选择**：数据预览/查询、节点/分片/索引/Mapping 表格支持主题色持久选中、跨行拖动多选、Ctrl/Cmd/Shift 与键盘选择、边缘滚动和清除；查询选择按稳定记录与标签保存，不因本地排序或翻页错位。
- **两文档精准对比**：查询/索引结果恰选两条后可本地对比，按原接收页/行核对，不按相同 `_id` 重查。元数据、`_source`、`fields` 和执行 runtime 分离；精确 JSON 值、缺失/null/空容器、来源/差异/字段筛选、分页、左右交换及原文复制。每记录 1 MiB，超限拒绝，不截断为完整对比。冻结原执行来源与记录，新执行/离开关闭，续页不替换；不额外查询或持久化结果，详见 [文档对比 QA](document-comparison-qa.md)。
- **单条文档结构化详情**：提供结构化/完整 hit JSON、JSON Pointer 搜索/复制、容器折叠与 50 项分页。元数据/source/fields/runtime 分开，精确 token、缺失/null/空容器保留，不把 JSON 路径当 Mapping/nested。打开时冻结真实接收页/行及来源；原值/容器/记录/原接收页复制不应用显示格式，新快照/离开关闭，不额外查询或持久化。1 MiB/hit、目录 4,096 节点/累计路径 1 MiB，超限整次拒绝，详见 [详情 QA](document-detail-qa.md)。
- **字段能力报告与保守门控**：字段列表默认名称与类型，按类型展开能力报告/限制索引/未知状态，原报告与保守门控分离。来源核对同连接 ID/端点/精确请求目标；刷新中/失败不展示旧能力，字段诊断拒绝不代表查询被拒绝。来源正文和索引成员按需挂载，每页 20 个索引，原 150 字段上限保持；未分列不代表不存在，也不推断 Mapping/nested、查询期 runtime 或旧执行值，详见 [字段能力 QA](field-capabilities-qa.md)。

### 1.5 连接安全与集群管理
- **设置界面交互**：设置固定左侧导航，连接/模型/集群/节点/分片/索引在右侧切换，返回不丢草稿。左右面板可调整宽度，资源栏 160-340px、AI 280-640px，窄窗口 AI 为覆盖层。启动、连接切换、设置和语言/主题变化不自动执行查询或预览。
- **只读集群监控**：设置健康/节点/分片/索引只读页面已接受限 IPC，无自动轮询。统一主题化下拉框、复选框/单选框、滑块、禁用/错误/焦点与模态样式；支持的 Chromium 渐进增强下拉弹层，其他引擎保留原生回退。索引/Mapping 元数据刷新失败保留旧列表并标记；字段能力刷新中/失败则不展示旧证据。动作样式限定按钮，分片角色不继承深色按钮背景；详见 [预览与行选择验收](preview-and-row-selection-qa.md)。
- **外观与偏好定制**：系统/日夜、四种强调色、中英文、独立字号/字体/密度、局部重置、启动偏好。快速跳转、命令面板、键盘导航、IME 保护、对话框焦点与未保存草稿关闭确认。
- **连接元信息与凭证管理**：设置内连接元信息与 Basic/API Key/Bearer 添加、编辑、保留/替换/解绑/删除，稳定 ID、顺序、选择与回退。秘密不回填或持久化到前端，HTTP 显示未加密风险；浏览器拒绝保存认证材料。保存已提交但旧凭据清理未完成时单独提示并支持有界重试。
- **自定义 CA PEM 绑定**：自定义公共 CA PEM 与连接绑定，默认根/证书/主机名验证保留，没有跳过验证开关；换端点不沿用旧凭据或 CA。
- **显式身份与权限诊断**：显式身份/角色与 monitor/read/view_index_metadata 诊断，权限不足、未知和不支持分开，不用 monitor 结果阻止索引搜索。原入口已加入精确报告版本/Serverless、许可与功能证据，不按主版本或许可证类型标操作可用；404 保持未知，未许可/未启用/实际未探测分别显示。只有许可/功能报告在后端内存缓存 60 秒、最多 16 连接；绑定传输/CA/集群/精确版本与请求代次，身份/目标权限/根信息每次重新检查，显式刷新绕过缓存，过期不轮询。诊断不开放 Graph/语言或写入 API。详见 [能力诊断 QA](connection-capabilities-qa.md)。
- **Rust 系统密钥库集成**：Windows keyring 后端、秘密清理、固定命名空间和脱敏错误；schema v2 加入凭证引用与持久清理队列，Rust 内部已有保存/轮换/解绑/删除与失败恢复编排。模型与 ES 凭据均已接受限设置 IPC；旧元信息入口仍拒绝已绑定凭证的行，新设置入口返回真实认证元信息和清理结果。macOS/Linux 密钥库仍明确不可用。
- **三种认证类型与快照隔离**：Basic/API Key/Bearer：密钥库负载版本化，API Key 保存 ID/key 组件并仅编码一次；认证只从数据库生成的不可变快照解析，绑定连接 ID、端点、类型与引用，覆盖身份/资源/搜索/PIT。秘密缺失、密钥库不可用或负载损坏不降级为无认证请求，三类错误有中英文诊断。详见 [C01.3 验收](connection-auth-qa.md)。

### 1.6 数据视图 (Data Views) 与字段增强
- **本地 Data Views 视图库**：支持创建/编辑/筛选/删除确认，最多 100 项/256 KiB；定义绑定稳定连接 ID、索引/别名/数据流/多目标模式与可选默认时间字段。同连接视图明确应用到查询草稿，跨连接明确新建查询；不改 DSL、不执行、不改变索引标签。所选定义以副本随草稿保存恢复，库中修改/删除不重绑旧草稿或结果，手改目标解除关联。默认时间字段复用显式字段发现；未验证、缺失、类型冲突、非日期与不可搜索各有提示，不把失败刷新或部分索引不可搜索标为全目标可用。详见 [Data Views QA](data-views-qa.md)。
- **字段格式化白名单**：每视图最多 32 项/16 KiB 的字段格式：数字分组、精确百分比/IEC 字节、UTC 日期，日期来源明确为含时区 ISO 或整数 Unix 毫秒，纳秒小数保留；类型不符/非法日期/超限显示原值。表格只格式化现有列与有界标量数组，不展开嵌套对象；格式在执行前深冻结，续页与历史恢复不回查库。原值开关不重查，选取格式化单元格复制完整原值，排序、JSON/文档复制和 CSV/JSONL 仍使用原数据。无任意脚本/HTML/URL 格式器，不把显示配置带入搜索/PIT 请求或全量导出 DSL。详见 [字段格式 QA](data-view-field-formats-qa.md)。
- **查询期运行时字段 (Runtime Fields)**：支持 keyword/long/double/boolean/date/ip/geo_point，每视图最多 32 项/64 KiB，可从同名 `_source` 取值，或使用每段最多 4 KiB 的内联 Painless。无 lookup/composite/存储脚本/参数/忽略脚本错误选项；脚本只在显式执行时由 ES 编译，不在前端执行。先审核遮蔽证据与最终 DSL，再显式应用到草稿；不同的手写同名 runtime 定义不覆盖，草稿/目标变化须重审，应用、保存、恢复及语言变化不执行。后端独立校验首屏/PIT 的同一白名单。执行/历史保留定义副本；只有执行 `rawDsl` 中的字段生效，表格读取相应 `fields` 原值，缺失不回填旧 `_source`，文档/JSON 原文与已加载导出不被重写。PIT 不冻结脚本输出。详见 [查询期字段 QA](data-view-runtime-fields-qa.md)。

### 1.7 导出与查询资产交换
- **查询参数化模板**：支持字符串、数值、布尔、空值、对象和数组，使用整值 `{"$param":"name"}`，不插值键名、字符串片段或索引。先预览最终 DSL，再显式应用；草稿变化阻止旧预览覆盖，不执行查询、不改变旧结果快照。最多 32 参数，模板/最终 DSL 256 KiB，单值 64 KiB。定义可保存恢复，未应用输入值不持久化；已应用 DSL 仍遵循草稿/历史保存规则。
- **查询库与 JSON 定义交换**：支持本地 JSON 定义交换：显式选择与审核，最多 100 定义/4 MiB；参数化条目导出模板，不含实际连接 ID/端点、认证、凭据引用、结果或历史。已知敏感键/认证值会阻止交换，其他字面量仍需用户核对。导入逐项明确映射本地连接或保持未绑定，原子新增、不覆盖旧查询，不打开或执行查询；普通查询库保存及导入均比较已读内容，冲突需明确重载。本地 Data View 绑定/ID、默认时间字段、字段格式与 runtime 配置不随该查询交换导出；已显式应用的 runtime DSL/脚本文字属于查询定义，仍须核对其字面量。本地时间托管同样不交换，须额外确认：具体草稿保留预览时的绝对边界，参数化查询仍用模板。详见 [参数与交换 QA](query-parameters-and-exchange-qa.md)。
- **基于独立 PIT 的全量流式导出**：另有独立 PIT 的全量 CSV/JSONL 流式导出，显式确认原执行目标、最终 DSL 与行数/文件限额。CSV 固定 `_index,_id,_source,fields` 文档列，JSONL 完整 hit，数值与转义保留。单任务、每批最多 1,000 行/响应 1 MiB、总最多 1,000,000 行/1 GiB/30 分钟扫描预算；空页才确认结束，原生选择目标后写同目录 `.partial-*`，完整刷盘后替换。取消/限额/部分/失败不报完整保存，未知文件/PIT 清理单列；进度可收起和重开，切标签/设置不重发，原标签关闭会停止。全量导出继续拒绝 `runtime_mappings` 和脚本，不从 PIT 推断计算结果稳定。详见 [导出 QA](snapshot-export-qa.md)。
- **工作区自动恢复**：自动保存查询/索引标签、活动上下文、未保存 DSL/无效可视化草稿、结果视图与列布局；重启只恢复定义，不执行、不恢复旧结果/页码/行选择/PIT、不重绑已删除连接。最多 50 标签/4 MiB。详见 [恢复批次 QA](workspace-recovery-qa.md)。
- **有界执行历史**：区分首屏查询、索引预览与续页的成功/部分/失败/取消，未知完成记为中断；可筛选、删除、恢复为新查询，最多 100 项/4 MiB，不保存结果正文或认证对象。查询/续页历史保存当次 Data View 定义副本（含字段格式和 runtime），不按当前库或连接重新绑定。时间定义与实际边界独立冻结；收藏恢复保留相对意图，历史恢复仅还原当次绝对 DSL、不重新计算。修订号 CAS 与串行保存阻止旧写覆盖；损坏/未知版本/冲突有提示，明确重载成功后才丢弃当前编辑。

### 1.8 存储架构与 AI 助手
- **桌面 SQLite 架构 (schema v10)**：兼容 main/dev 两种 v9 图表表结构，补齐缺表但不重写任何旧定义、连接 ID 或修订号；保留 v8 固定筛选库、v7 数据视图库、v6 工作区恢复、v5 公共 CA/查询库和 v4 模型凭据。各库独立 CAS、损坏/未知版本/冲突不覆盖，新增定义核对连接存在；秘密只存系统密钥库。迁移前核对已知历史 DDL，异常表结构不自动修复；定义文档版本和恢复合同未因 schema 升级改变。
- **多模型配置**：模型设置支持自定义 HTTP/HTTPS 地址、端口、基础路径、模型 ID，HTTP 只作未加密提醒。可显式获取兼容协议 `/models` 或 Ollama `/api/tags`，也可手填；真实生成测试只在完整非空回复后标记通过，保存配置或获取列表不等于测试通过。
- **AI 对话面板**：AI 支持兼容 Chat Completions/Ollama 流式、多轮完整历史、取消、末条失败重试与安全 Markdown。Enter 直接发送并立即清空当次输入/附件，Shift+Enter 换行，IME 不误发；只有显式附加时发送查询草稿快照，不自动携带结果或跨目标转发历史。模型工具在底部输入区，消息/代码内部滚动；会话只在内存中保留。详见 [AI 验收](ai-chat-and-installer-qa.md)。
