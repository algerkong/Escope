最新首页决策：查询工作台的索引打开入口为默认页，AI 默认收起；管理能力归入设置的高级入口。
明确打开索引新增独立数据标签，连接 ID + 索引去重，重复打开仅定位；各标签草稿、结果和列设置不得被覆盖。
F02/D03 按此实现，不能再次用概览页作为默认首页。查询结果、条件与视图必须在设置往返后保留。
设置中的连接/模型/集群/节点/分片/索引在右侧内容区显示，左侧设置菜单固定保留；
禁止用独立管理首页或配置弹窗替代此交互。

连接选择决策：优先恢复上次有效连接 ID，否则默认列表第一项；只有一个时隐藏选择器。
多个连接可在首页右上角和连接中心选择，两处同步；连接名称可配置和重命名，身份不随名称改变。
列表采用持久化顺序，不因名称排序、重命名或页面筛选改变“第一项”。
零连接时正式应用显示添加连接空状态；原型独有的演示连接不能作为正式产品的真实默认连接。

## 1. 执行原则

- 原型可复用布局、文案、token 与测试场景，但不把全局脚本直接搬进生产应用。
- 生产基线：React + TypeScript + Vite + Tailwind 4 + Tauri 2/Rust，SQLite 元信息与系统密钥库分离。
- React 组件、路由、状态、国际化、领域模型、IPC、网络适配分层，不继续扩张单文件脚本。
- 页面需要加载、空数据、无权限、不支持、过期、失败、部分成功和取消状态。
- ES 8.x 选择具体测试小版本锁定，7.17 与 9.x 分别验证；OpenSearch 使用单独兼容驱动任务。
- 任务验收以可复现用例为准，不以“接口返回 200”“页面画出来”作为完成标准。
- 原型现有连接与模型目录不算正式功能完成，所有通信从受约束后端发起。

### 六方向确认后的查询子项边界

- Q02 补相对/绝对时间与时区、单元格包含/排除、筛选启停/固定、复杂布尔/nested 及服务器多字段排序。
  查询范围的改变由用户明确执行，不把当前已加载行排序改成隐式查询。
- Q03 保留 JSON 无损与撤销，增量接 Monaco/字段/参数补全。编辑器是数据探索前置，
  不因此开放 W11 的任意 REST 或混合批次。
- Q05 补文档对比/时间上下文/字段详情与行列虚拟化；只读取明确目标和有界范围，
  大结果性能与原生选择/复制分开验收。
- Q06 先指标、terms/date_histogram、字段 Top values/覆盖率/分布与常用图，
  再拆公式、同比/环比、多图层/双轴/参考线/注释；采样、近似和桶截断必须随图展示。
- Q07 先版本化草稿/收藏/历史/列布局恢复，再已加载结果导出及 PIT 快照流式导出，
  最后参数/本地配置交换；数值无损、CSV 防护、磁盘/取消/部分文件与配额纳入验收。
  配置交换排除凭据、认证头与系统密钥库引用；跨环境导入需明确映射连接，
  不按连接名称自动重绑目标，也不恢复旧环境认证。
- Q09 的 runtime fields 先限查询期和本地视图定义，服务器 Mapping 更新仍由 W04 审核，
  不能从字段编辑器绕过写入模式。
- Q06a/Q09/Q10/Q11 本轮只是纳入并定义任务，尚未实现。大型父任务在派发前仍需拆成明确的小项。
