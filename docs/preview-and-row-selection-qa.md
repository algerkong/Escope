## 实际交付

| 反馈 | 实现 | 验收边界 |
| --- | --- | --- |
| 预览头部冗余 | 索引预览只保留一个 `preview-toolbar`，合并连接/索引、成功图标或异常状态、命中数、耗时、视图与操作；移除重复“数据预览”标题、地址行和重复文档计数 | 查询编辑器仍保留执行来源，过期/部分失败/取消提示不隐藏 |
| 预览底部冗余 | 已加载行数、本地排序范围、分页、列设置、加载更多合并到表格底栏；快照说明和服务页数进入加载按钮 tooltip；JSON 底栏保留最新响应页与复制 | 本地页与 ES 续页语义不变，原始响应不重写 |
| 全局底栏 | 只读缩为带可访问名称与 tooltip 的盾牌；无连接/实际测试结果仍可见，不再重复显示未测试 | 不把已读到文档误报为身份测试通过 |
| 设置黑块 | 主分片使用 `cluster-role` 与 `data-role`，不再复用通用 `primary` 类；全局三类动作样式用 `:where(button)` 限定元素且维持原特异度 | 主/副本/未知角色为主题文字，按钮背景、compact 尺寸和交互保持 |
| 持久行选择 | 查询/预览使用 TanStack 行选择受控状态；节点、分片、索引与 Mapping 表格共用行手势逻辑；选中背景与左侧细标记使用当前主题色 | 排序、分页、JSON/查询标签/设置往返保留查询选中 ID；新执行或元数据刷新清空对应选择 |
| 多选与拖动 | 左键跨行拖动连续选中，可反向和缩小范围；Ctrl/Cmd 追加/取消，Shift 范围，方向键/空格/全选/清除；边缘滚动限于当前已呈现页 | 不隐式执行、续页或修改数据；按钮、列头、拖列、列宽与文本编辑不参与行选择 |

命中数通过 `Intl.NumberFormat` 格式化 `BigInt`，响应中的超大整数保持精确；
遵循千分位偏好，未知总数不变成零，`gte` 仍明确为下界。

## 交互与身份

- 行选中独立于 hover，指针离开后保持主题背景；浅色、深色与强调色复用语义 token。
- 查询选中使用收到页号与页内位置，不使用排序后的行号；同索引同文档 ID 的不同返回行也不合并。
- 分片行在同一次响应内使用独立稳定 ID，多个未分配副本即使其他字段相同也不合并。
- Shift 范围基于当前筛选/排序顺序，分页仅改变显示；Ctrl/Cmd+A 只涵盖当前已加载且参与展示的数据。
- 单行内保留原生文字拖选，跨行后切换为行范围并清除冲突的文字高亮；Alt 拖动可保留原生文本行为。
- 松开鼠标、失去窗口焦点、隐藏/卸载表格和新执行会终止拖动与边缘滚动；已完成的选择不会因松开消失。
- 行内详情按钮与双击详情仍保留；Ctrl/Cmd+Enter 仍交给工作区执行快捷键。
- 高对比模式使用系统 Highlight/HighlightText，选中和焦点标记不通过改变列宽实现。
