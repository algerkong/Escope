# 设置与快捷操作设计

## 预览与表格选择（2026-10-09）

- 索引预览使用一条 `preview-toolbar` 显示绑定连接/索引、结果状态、命中与耗时及视图/操作，
  不重复显示标题、HTTP 地址或已加载文档计数。表格底栏合并行数、本地页、列设置和继续加载；
  快照说明按需悬浮显示，失败/取消/部分结果与过期仍直接可见。
- 分片角色仅为主题文字，不复用主按钮的 `primary` 类。全局动作样式限定 button，保留控件尺寸。
- 数据表格单击保留主题色选中，跨行拖动为连续范围，可反向或缩小；Ctrl/Cmd 追加/取消，
  Shift 连选；方向键/空格、Ctrl/Cmd+A 和清除入口可用。选择不发起网络或写操作。
- 查询选中绑定返回记录，排序/分页/续页/JSON/标签/设置往返保持；新执行清空。
  节点/分片/索引/Mapping 采用相同交互，数据刷新后清空，选择不跨应用重启持久化。
- 同一行内保留原生文本拖选，跨行优先行范围；Alt 拖动可保留文本行为，行内操作按钮不触发行选择。
  松开鼠标、失焦、切走或卸载结束拖动；靠近滚动边缘继续选择当前呈现页，不自动翻页或加载服务页。

## 索引与查询标签（2026-10-08）

- 数据预览入口只用于打开索引；每个连接 ID + 索引独立新增数据标签，与查询标签并列。
  再次打开同一目标仅定位已有标签，不重新执行。刷新是当前标签内的明确动作。
- 索引标签目标锁定；从该索引新建查询时创建独立草稿，不修改索引标签。
  表格布局、结果视图、页码、滚动和可视化未完成条件均按文档保留，暂不跨应用重启保存。
- 激活有效连接的标签同步顶部连接、资源栏与新查询上下文，持久化选择失败可重试；
  旧选择回调不得覆盖新意图。已删除连接的历史标签仍保留原身份，不重绑为其他连接。
- 关闭活动标签回到相邻标签，后台关闭不移动编辑焦点；关闭全部文档后保留空入口。
  文档区域支持 Ctrl+W / macOS Cmd+W，AI/资源输入区不拦截；macOS Control-W 保留文本操作。
- 设置往返、连接和标签切换不发起查询；快速跳转包含索引标签。原生拖动/键盘和缩放效果单列人工验收。
- 正式表单统一选择框、复选框/单选框、滑块与焦点样式，不改变现有主题或设置导航结构。
  支持的引擎采用可样式化 select 弹层，其他引擎保持原生弹层回退。

## 工作区恢复与执行历史（2026-10-09）

- 无恢复记录时仍默认索引打开入口；已有记录时恢复有序查询/索引标签及活动上下文。
  仅恢复定义，不执行查询、预览或 PIT；启动 AI/默认新查询视图仍按偏好生效。
- 未保存 DSL、无效可视化草稿、每标签 table/JSON 和列顺序/宽度/显隐/已加载行排序可恢复；
  结果正文、页码、行选择、PIT 和 AI 会话不跨重启保存，已删连接的标签不重绑。
- 标签下方提供紧凑保存状态与查询库/执行历史图标，索引入口和索引标签也可访问。
  历史区分查询、预览和续页；失败/取消不写成功，未知完成记为中断，恢复为新查询不执行。
- 桌面使用独立 SQLite 恢复行（schema v6 / 文档 v1）；最多 50 标签，历史最多 100 项，
  工作区与历史各 4 MiB，单份 DSL 256 KiB。历史按容量淘汰最旧条目，不是完整审计日志。
- 写入串行并比较修订号；损坏、旧/未知文档版本或冲突不清空覆盖。
  显式重载有丢弃当前会话编辑/结果并停止请求的确认，读取失败仍保留当前编辑。
  浏览器为明确的 session 内存适配，不承诺刷新后恢复，也不作为 SQLite 失败降级。

自动化与待人工边界见 [恢复批次 QA](workspace-recovery-qa.md)。

## 融合式窗口顶栏（2026-09-30）

用户新增要求：移除独立的系统标题栏，把窗口管理与当前 header 融合为一层。
这不是替换已有工作台信息架构；保留品牌、当前连接、快速跳转、命令和设置入口。

- macOS：原生交通灯与 overlay titlebar，隐藏重复窗口标题；header 左侧预留原生按钮安全区，
  不绘制假交通灯。全屏状态下预留区与窗口控件按系统状态处理。
- Windows：移除传统标题栏，右侧紧凑的最小化、最大化/还原、关闭；关闭热区有危险色反馈，
  其余控件沿用当前灰阶与主题 token。
- Linux：无装饰窗口与紧凑 CSD 风格控制；不是模拟某一发行版的服务器端标题栏，
  按钮布局/拖拽/缩放需在目标桌面环境验证，不承诺所有 compositor 行为一致。
- 空白区用于拖拽，业务按钮/下拉框不拖动；Windows/Linux 空白双击切换最大化。
  失败可见且只显示本地化提示；不能用 destroy 绕过正常 close 事件。
- 浏览器预览不出现假窗口控件，不调用桌面 API。保持中英文、暗色、大字号与可见焦点，
  不新增第二行装饰性标题栏，不在 header 放操作教程。

实现归入 F02.2。原生系统菜单、Windows Snap hover、macOS 全屏与 Linux Wayland/X11
单列集中人工验收；自动化只验证组件、API 委派、配置和生命周期，不冒充跨平台实测。

## 最新视觉规范

依据用户提供的常规设置截图调整全部设置视图：左侧浅灰导航、搜索框、
“个人 / 集成 / 集群资源”分组，选中项使用浅灰底而非大面积主题色。
右侧顶部对齐，标准表单内容最大宽度 810px（包含内边距），管理表格最大宽度 1240px。
常规、外观、字体、快捷键采用薄边框分组、组内分割线、右侧紧凑控件，圆角不超过 8px。
开关有键盘焦点与高对比模式回退，强调色仍由用户主题控制。
连接/模型/集群/节点/分片/索引沿用同一设置容器，详情与编辑表单同步采用紧凑样式。
这些是 EScope 参数，不声称从截图精确提取字体或像素。查询首页样式不在本次修改范围。
新增样式位于 settings-design.css，结构分组由 settings-style.js 完成；现有控件事件保持不变。

设置右侧统一顶部对齐（纵向 margin 为 0），只水平居中，短页面不随内容高度上下居中。
常规页分为“语言与格式”和“启动与查询”：语言、显示时区（系统/北京/UTC）、
日期格式、数字千分位、启动时展开 AI、启动时结果视图、JSON 自动换行。
格式设置立即改变显示，不修改原始 JSON、查询条件或重新执行；启动选项下一次打开应用生效。
常规恢复默认仅重置上述新偏好，不清除语言、连接、主题、查询和模型配置。
原型已保存这些偏好并实现展示行为；生产版本仍需 Intl、持久化与跨平台回归。

工作区连接规则：以稳定连接 ID 保存上次选择；记录不存在或已删除则选第一项。
只有一个连接时直接使用且不显示下拉框；多个连接在右上角和连接中心均可手动选择。
连接中心支持名称配置与重命名，名称不是身份标识。移除当前连接后回退第一项。
无真实连接时原型提供明确标记的 Commerce 演示连接；一旦配置真实连接，不将演示连接混入默认选择列表。
真实连接尚未接通时隐藏演示查询及监控结果，显示未连接状态，不因选择配置而发起查询。

最新交互约定：连接中心、AI 模型、集群概览、节点、分片和索引均作为设置左侧菜单项，
直接渲染在同一设置页右侧，沿用外观/常规的内容切换模式。不另开配置弹窗，
不跳转到独立管理首页，不显示第二套资源导航。具体记录的详情/新增确认仍可使用局部对话框。
返回查询只由明确的返回入口触发，保留条件、执行结果和视图。

完整平台范围与模型设置新增内容见 [桌面管理工作台设计](platform-design.md)。
模型凭证与提供方配置留在设置中；AI 面板保留本次会话的模型选择器，支持用户手动选择。
快速跳转后续覆盖节点、分片、索引、快照等真实资源，命令经统一操作与权限注册表执行。

## 视觉与入口

依据用户提供截图的布局意图设计：左侧设置分类，右侧限宽、留白充分的表单。
不是对 ChatGPT 品牌或像素的复制。外观、语言、字体不出现在主查询工具栏。
工作台保留设置、快速跳转、命令面板入口；设置是独立应用视图，返回后恢复查询状态。
桌面正式版设置入口放在资源栏底部，窄窗口保留可见入口。
使用现有 Tailwind 语义 token，小圆角、横向分割线，不嵌套卡片。

## 完整设置目录

| 分类 | 内容 | 生效与安全规则 |
| --- | --- | --- |
| 常规 | 中英文/系统语言、启动恢复、时区、日期格式 | 切换语言不重查；时区改变提示影响范围 |
| 外观 | 系统/日/夜预览块、强调色、减少动态效果 | 即时预览并保存，错误/警告色独立 |
| 字体与密度 | UI/代码字体，UI/代码/表格字号，行高、密度 | 独立调节、范围校验、局部恢复默认 |
| 查询与结果 | 页大小、超时、默认时间字段、返回字段、JSON 换行 | 新查询默认值，不静默改动已有草稿 |
| 连接与网络 | 连接配置、认证、CA、代理 | 凭证写系统密钥库，配置保存前校验 |
| AI 模型 | 提供方、模型、回答语言、测试、超时 | 不因打开设置自动发送数据 |
| 隐私与安全 | 字段/样本授权、脱敏、历史保留、本地清理 | 生产连接可覆盖为更严格策略；清理须确认 |
| 导出 | 默认格式、编码、字段顺序、CSV 安全模式 | 完整导出仍需本次范围确认 |

| 关于与更新 | 版本、许可、诊断、更新策略 | 诊断脱敏，不默认上传 |

当前 HTML 原型实现常规语言、外观、字体与密度和默认快捷键查看。
其他目录是产品规范，不提供无效开关；自定义快捷键录制、系统字体枚举、真实模型设置尚未实现。
字体枚举需由桌面后端完成；当前选择只是系统字体栈，缺少指定字体时回退。
不默认开放任意背景/前景配色，避免破坏对比度；高级自定义主题导入留后续并校验 schema。

## 字体设置

UI 默认 14px，代码默认 13px，表格默认 13px；原型范围均为 12–20px。
UI 通过根字号与相对字号影响导航、设置和标题；代码与表格分别使用自己的 token。
显示密度只控制留白，不偷偷改变字体。字体放大后行高与控件自适应，不裁切文字。
即时应用、持久保存；恢复排版默认值仅改变字体、字号和密度，不重置主题或语言。
正式版本启动前恢复所有视觉设置，避免闪烁；存储不可用提示“本次会话生效”。

## 两个快捷面板

Ctrl+P 为快速跳转：已打开查询、收藏、连接/索引与设置目的地。
Ctrl+Shift+P 为命令面板：执行动作，如切换视图、打开设置、显示 AI、格式化 DSL。
原型快速跳转只展示已存在的查询和设置页面，不伪装其他索引可访问。

面板居中靠上，宽约 620px，搜索框自动聚焦。
支持中英文关键词、上下选择、Enter 确认、Esc 关闭、空结果和鼠标选择。
关闭无动作时恢复原焦点；执行跳转后聚焦目标标题或编辑区。
正式产品匹配名称、别名、路径；排序优先精确匹配、当前上下文和最近使用。
连接切换和查询执行分开，跳转到索引不自动运行原查询。
命令使用稳定 ID、翻译键、适用上下文、可用条件和风险级别，按钮与快捷键共用执行入口。
不可用命令解释原因；危险操作不能因为来自命令面板而省略确认。

| 操作 | Windows/Linux | macOS | 范围 |
| --- | --- | --- | --- |
| 快速跳转 | Ctrl+P | Cmd+P | 应用内 |
| 命令面板 | Ctrl+Shift+P | Cmd+Shift+P | 应用内 |
| 设置 | Ctrl+, | Cmd+, | 应用内 |
| 执行查询 | Ctrl+Enter | Cmd+Enter | 正式版查询工作区 |
| 保存查询 | Ctrl+S | Cmd+S | 正式版查询工作区 |
| 新查询 | Ctrl+N | Cmd+N | 正式桌面版 |
| 关闭标签 | Ctrl+W | Cmd+W | 正式桌面版，未保存确认 |
| 查找 | Ctrl+F | Cmd+F | 正式版当前编辑器/结果视图 |
| 关闭最上层浮层 | Esc | Esc | 对话框优先，不顺带关查询 |

HTML 原型实现前三项及 Esc，其他为规划，不宣称生效。
浏览器可能保留打印等快捷键，因此始终提供鼠标入口；正式 Tauri 版统一配置应用菜单加速键。
仅注册应用内快捷键，不抢占操作系统全局按键。
中文输入法 composing 时不执行快捷命令，长按不反复打开面板。
编辑器与应用快捷键集中仲裁，优先级为对话框、命令面板、编辑器、工作区。

## 验收

主题与中英文原有组合之外，覆盖最小/最大字号、两档密度、窄窗口和 200% 缩放。
验证设置切换不改文档、不重新查询；刷新偏好恢复；坏配置回退；快捷面板焦点不逃逸。
验证中英文搜索、零结果、键盘滚动、IME、连续调用、Esc 分层与鼠标入口。
桌面三平台分别测试 Cmd/Ctrl 和原生菜单冲突，不能以浏览器测试替代。
